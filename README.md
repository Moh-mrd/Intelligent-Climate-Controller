# SMART CLIMATE AI — Intelligent Climate Controller (Fuzzy Logic)
Mamdani fuzzy controller (scikit-fuzzy) with a Streamlit dashboard. Module RC, Chapter 3, Université de Batna 2.

## Features
Live dashboard + gauge, fuzzification view, membership plots, rule engine, simulation lab (CSV export), 3D decision surface, learning page.

## Run locally
```
pip install -r requirements.txt
pytest
streamlit run app.py
```
## Deploy
1. Create a GitHub repository. 2. Upload all project files. 3. Open https://share.streamlit.io/ 4. Connect GitHub.
5. Select the repository. 6. Select `app.py` as main file. 7. Deploy.
